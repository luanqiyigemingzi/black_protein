# black_protein
This is an FPGA project code. It was developed using China's Anlogic EDA software, and its specific functions include:
(1) Receiving simple commands from a PC via Ethernet to control the LEDs and seven-segment displays on the development board;
(2) Receiving images from a PC host via Ethernet to control VGA, HDMI, or LCD display on the development board;
(3) Sending images stored on the development board (in the TF card or SPI Flash) to the PC host via Ethernet for display;
(4) Using an external camera module on the development board for video input, transmitting it to the PC via Ethernet for display;
